# SQL Practice & Learning

A structured collection of SQL concepts, queries, exercises, and hands-on practice covering beginner to advanced SQL. This repository documents my learning journey, strengthens my problem-solving skills, and builds a solid foundation for working with relational databases and data analytics.

## 📚 Topics Covered

- SQL Fundamentals
- Database Basics
- SELECT, WHERE, ORDER BY, DISTINCT
- Data Manipulation (INSERT, UPDATE, DELETE)
- Data Definition (CREATE, ALTER, DROP)
- GROUP BY & HAVING
- Joins (INNER, LEFT, RIGHT, FULL)
- Filtering and Sorting Data
- String & Date Functions
- Window Functions
- Aggregate Functions
- Subqueries
- Common Table Expressions (CTEs)
- View
- Indexing
- CTAS
- Temp Tables
- CASE Statements
- Stored Procedure
- Constraints

## 🎯 Objectives

- Develop strong SQL fundamentals.
- Understand how relational databases work.
- Solve SQL problems independently.
- Practice data manipulation and analysis.
- Improve query-writing and logical thinking.
- Prepare for Data Analyst and Data Engineer.
